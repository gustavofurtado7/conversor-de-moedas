# 💱 Conversor de Moedas

Projeto desenvolvido para colocar em prática meus conhecimentos em **HTML5, CSS3 e JavaScript**, criando uma aplicação capaz de realizar conversões entre diferentes moedas.

O **Conversor de Moedas** foi desenvolvido como parte da minha jornada de aprendizado em desenvolvimento web, unindo a construção de uma interface com a implementação de funcionalidades utilizando JavaScript.

## 🚀 Sobre o projeto

A proposta do projeto foi desenvolver uma aplicação simples e funcional para **converter valores entre moedas**, permitindo ao usuário inserir um valor e visualizar o resultado da conversão.

Além da construção visual da página, o projeto também foi uma oportunidade para praticar conceitos de **lógica de programação, manipulação do DOM e interação com os elementos da interface através do JavaScript**.

Esse projeto representa uma evolução em relação aos meus primeiros projetos, passando de páginas focadas principalmente em HTML e CSS para uma aplicação que também possui **comportamento e lógica implementados com JavaScript**.

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura e organização da aplicação
* **CSS3** — estilização e construção da interface
* **JavaScript** — lógica de conversão e interação com a página

## 📚 Conceitos praticados

Durante o desenvolvimento do projeto, foram praticados conceitos importantes de desenvolvimento front-end:

* Estruturação com HTML5
* CSS3 e estilização de interfaces
* Organização e posicionamento de elementos
* Manipulação do DOM
* Seleção de elementos com JavaScript
* Eventos e interações do usuário
* Funções
* Variáveis
* Operadores matemáticos
* Conversão e manipulação de valores
* Formatação de valores monetários
* Integração entre HTML, CSS e JavaScript

## 🎯 Objetivo

O principal objetivo deste projeto foi **aprender e praticar JavaScript integrado ao HTML e CSS**, criando uma aplicação que, além de possuir uma interface, também apresenta uma funcionalidade real.

O projeto faz parte da minha evolução como desenvolvedor e representa um passo importante na transição de projetos puramente visuais para aplicações com **lógica e interatividade**.
